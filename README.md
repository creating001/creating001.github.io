# Jinqi Wu · 武锦旗

Personal academic website: [creating001.github.io](https://creating001.github.io).

Built with [PRISM](https://github.com/xyjoey/PRISM).

## Local development

Use Node.js 22 or later:

```bash
npm ci
npm run dev
```

Open http://localhost:3000. Run `npm run build` to export the site to `out/`.

## Updating content

- `content/`: English content and site configuration.
- `content_zh/`: Chinese content.
- `public/`: Photos, papers, and other static assets.

Push to `main` to deploy automatically to GitHub Pages.
